# YaCut — сервис сокращения ссылок и загрузки файлов

**YaCut** — веб-приложение на Flask, которое позволяет сокращать длинные URL,
задавать собственные короткие идентификаторы и загружать файлы на Яндекс.Диск
с получением коротких ссылок для скачивания. Проект поддерживает как работу
через веб-интерфейс, так и через REST API.

---

## Возможности

- Сокращение длинных ссылок с автогенерацией уникального 6-символьного id.
- Пользовательский короткий идентификатор (латиница и цифры, до 16 символов).
- Загрузка одного или нескольких файлов на Яндекс.Диск.
- Создание коротких ссылок на загруженные файлы.
- Скачивание файлов через короткую ссылку с корректным именем файла.
- REST API для программного создания коротких ссылок и получения оригинальных URL.
- Проверка занятости и зарезервированных идентификаторов.

## Основные роуты

| Метод | Роут | Описание |
|-------|------|----------|
| `GET`, `POST` | `/` | Главная страница: форма сокращения ссылки |
| `GET`, `POST` | `/files` | Загрузка файлов на Яндекс.Диск |
| `GET` | `/<short_id>` | Редирект по короткой ссылке или скачивание файла |
| `POST` | `/api/id/` | API: создание короткой ссылки |
| `GET` | `/api/id/<short_id>/` | API: получение оригинальной ссылки по id |

### Пример работы с API

Создание короткой ссылки:

```bash
curl -X POST http://localhost:5000/api/id/ \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/very/long/link", "custom_id": "mylink"}'
```
  Ответ 200 OK:
  {
    "url": "https://example.com/very/long/link",
    "short_link": "http://localhost:5000/mylink"
  }


### Установка и запуск

- Клонирование репозитория
```bash
  git clone <url-репозитория>
  cd yacut
```
- Виртуальное окружение
```bash
  python -m venv venv
  source venv/bin/activate      # Linux / macOS
  venv\Scripts\activate         # Windows
```
- Установка зависимостей
```bash
  pip install -r requirements.txt
```
- Настройка переменных окружения
  Создайте файл .env в корне проекта
- Применение миграций
```bash
  flask db upgrade
```
- Запуск
```bash
  flask run
```
  (Приложение доступно по адресу http://127.0.0.1:5000.)

### Переменные окружения
  FLASK_APP=yacut
  FLASK_ENV=development
  SECRET_KEY=ваш-секретный-ключ
  DATABASE_URI=sqlite:///db.sqlite3
  DISK_TOKEN=токен-яндекс-диска
